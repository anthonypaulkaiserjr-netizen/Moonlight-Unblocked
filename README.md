# Moonlight-Unblocked

SIMPLE EXPLANATION
This calls the Cloudflare service to be installed and puts Moonlight Web on your computer. You need to install Sunshine first.

INSTALL
1: Install the executable.
2: Read your Cloudflare address to connect to Web UI. It randomizes every boot of the program.
3: Go to the Sunshine Web UI (localhost://47990 by default) and pair Web Stream with Sunshine.
The default Web Server username and password is Sunshine and whatever password you set the first time you go to localhost://47990. You can chang the username and password by creating or editing a user.
